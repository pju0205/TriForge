# 🔫 Triforge (Dedicated Server FPS)
**Unreal Engine 5 기반의 멀티플레이어 1인칭 PvP 슈팅(FPS) 프로젝트**

> **🌐 Dedicated Server 기반의 안정적인 멀티플레이 환경 구축**
> **⚔️ 다양한 무기 시스템과 정교한 네트워크 동기화 구현**

### 🛠️ Tech Stack
- **Engine:** Unreal Engine 5
- **Language:** C++, Blueprint, JS, Http
- **Network:** Dedicated Server (AWS 활용)
- **VCS:** GitHub

### 🚀 Key Features
- **Dedicated Server System:** 클라이언트 권한을 제한하고 서버에서 모든 판정을 처리하는 보안성 높은 멀티플레이 환경 구축
- **Advanced Weapon System:** C++ 클래스 상속 구조를 활용한 다양한 총기(Rifle, Sniper 등) 및 발사 로직 구현
- **Network Replication:** 위치, 애니메이션, 체력 등 핵심 데이터의 완벽한 네트워크 동기화(Replication) 처리
- **Gameplay Framework:** GameMode, GameState, PlayerState를 활용한 체계적인 게임 규칙 설계
